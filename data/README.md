# Data

Use the project's original Kaggle dataset:

[NYC Taxi Trip Data — Google Public Data](https://www.kaggle.com/datasets/neilclack/nyc-taxi-trip-data-google-public-data/data)

Place these files here:

- `taxi_trip_data.csv` — the original 10M-row trip file.
- `taxi_zone_geo.csv` — the zone file with `zone_id`, `zone_name`, and `borough` columns.

The notebook expects these filenames and column names. Data files are not included because of their size.
